# QuizGenius-AI

QuizGenius-AI is a smart web application that generates quizzes from documents using AI.  
Users can upload text or documents and instantly receive automatically generated quiz questions.

---

## 🚀 Features

- Upload document or text input
- AI-powered quiz generation
- Multiple-choice questions
- Instant results and scoring
- Simple and user-friendly interface
- Fast and responsive design

## 🛠️ Technologies Used

- HTML
- CSS (Tailwind CSS / Custom CSS)
- JavaScript
- AI/ML API (if used)
- Git & GitHub
